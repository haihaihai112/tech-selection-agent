# 真实输出的助手复核（不是人工独立评审）

复核对象：`live-demo-final-deepseek.json` 两个报告版本。复核者为实施助手，未统计人工事实正确率。

两版共引用同一组 5 条 Milvus 原文事实：部署选项、Standalone Docker 部署、特定场景下的 DevOps 工作量、检索功能、Distributed 的来源规模声明。均能在保存的原文中定位；最后一项只是文档声明，不是本项目性能基准。其他两个候选产品没有足够已核验事实，不能据此排序或推断不支持。

发现的风险：第一版将 DevOps 工作量较少表述为“维护成本较低”，没有实际费用测量；第二版在推荐文字中新增了 Milvus 与 PostgreSQL 的架构关系，该说法没有被该推荐引用的事实支持。即使观点可能符合常识，也不符合本项目的证据边界。

已据此增加 Writer 判断的语义依据核验：产品架构、费用、能力等新增说法未经支持时，拒绝发布该次报告，保留任务证据。对应回归测试验证“有效引用编号 + 未支持的推荐文字”不能产生成功报告。此修复不修改旧报告与原始运行文件，也不能保证同一模型自检能够发现所有语义问题。

`human-review-template.csv` 留出了人工支持关系、冲突识别、不确定性表达、评审人和备注栏，目前均未填写。它是待评审材料，不是人工评审结果。
